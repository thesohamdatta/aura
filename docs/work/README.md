# Aura Work Artifacts

Use `docs/work/` for task-local specifications, research notes, plans, and verification evidence that need to survive across sessions.

## Rules

- Every substantive work item should have a small spec when the change spans multiple files or sessions.
- Link work artifacts from the PR or issue.
- Keep task artifacts scoped to the task.
- Promote durable discoveries into canonical project knowledge before closing the work item.
- Do not treat task-local notes as permanent architecture rules.
